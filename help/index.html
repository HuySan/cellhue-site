Formulas

Type them in any cell, like any other formula.

FunctionWhat it returnsPlan
SUMBYCOLOR(range, color)Sum of numbers whose fill color matchesFree
COUNTBYCOLOR(range, color)Number of cells whose fill color matchesFree
AVERAGEBYCOLOR(range, color)Average of numbers whose fill color matchesFree
SUMBYFONTCOLOR(range, color)Sum of numbers whose font color matchesPro
COUNTBYFONTCOLOR(range, color)Number of cells whose font color matchesPro

Examples:

=SUMBYCOLOR(A2:A50, "#ff0000")
=COUNTBYCOLOR(B2:F100, "#00ff00")
=AVERAGEBYCOLOR(A2:A50, C1)
=SUMBYFONTCOLOR(A2:A50, "#0000ff")
=COUNTBYFONTCOLOR(A:A, "#ff0000")
  • COUNT counts every cell with the color, empty cells included.
  • SUM and AVERAGE use numeric cells only. If no cell of that color holds a number, AVERAGE shows a message instead of a result.
  • If your spreadsheet uses ; between arguments (for example, in many European locales), write =SUMBYCOLOR(A2:A50; "#ff0000").
  • Formulas inserted by Cellhue have a third argument, CELLHUE_REFRESH. It lets Cellhue recalculate them when colors change. Keep it.

Choosing the color

The second argument can be:

  • A color code in quotes: "#ff0000" or the short form "#f00". Upper and lower case both work.
  • A sample cell, like C1. Cellhue uses its fill color (or its font color for the font functions).

If the color code is not valid, the cell shows Cellhue: invalid color, use a cell or "#rrggbb". Color names like "red" are not supported.

The sidebar

  1. Open Extensions → Cellhue → Open sidebar.
  2. Choose Fill color or Font color (font color is Pro).
  3. Select a range in the sheet and click Analyze selection. You see every color in the range with its cell count, sum and average.
  4. To keep a result in the sheet, click a color in the list, pick Sum, Count or Average, click an empty cell outside the range, then click Insert formula. Cellhue writes a formula with the color code, for example =SUMBYCOLOR(A1:A20, "#ff0000", CELLHUE_REFRESH).

Refresh and auto-refresh

Google Sheets does not recalculate a formula when only a color changes. Cellhue updates its formulas in these ways:

  • When you open the file (Free and Pro).
  • Refresh all: Extensions → Cellhue → Refresh all, or the Refresh button in the sidebar. It also adds CELLHUE_REFRESH to formulas you typed by hand, so they can be refreshed later.
  • Auto-refresh (Pro): while the sidebar is open, Cellhue checks the colors of the ranges used in your formulas and recalculates when they change. It checks every 3 seconds after a change, then less often, up to every 30 seconds, when nothing changes. Checks pause while the browser tab is in the background. A new color may take up to about 35 seconds to show in the results.

To refresh, Cellhue keeps a small hidden sheet named _cellhue with the named range CELLHUE_REFRESH. Please do not delete it.

Free limit

On the Free plan, a formula range or a sidebar selection can have up to 1,000 cells. Larger ranges show Cellhue Free: up to 1000 cells. Pro removes the limit. Whole-column ranges like A:A count only down to the last row with data.

Activating Pro

  1. Buy Pro ($19, one-time payment). Payments are handled by Polar.
  2. Polar emails you a license key like CELLHUE-XXXX-XXXX-XXXX. It is also on your order page and in your Polar customer portal.
  3. In Google Sheets open Extensions → Cellhue → Enter license key. The sidebar opens: paste the key and click Activate.

One key can be activated on up to 3 Google accounts. To free a slot, remove an activation in your Polar customer portal.

Cellhue re-checks the key with Polar each time you open the sidebar. If the sidebar has not been opened for 30 days, Pro formulas show Cellhue Pro: open the Cellhue sidebar to re-check your license; opening the sidebar fixes it.

Known limitations

  • Use a direct range like A1:B10, A:A, 'Sheet 2'!A1:A9 or a named range. Ranges built with INDIRECT, OFFSET or arrays are not supported.
  • Put each color formula in its own cell if a formula uses the same function twice on ranges with identical values.
  • Colored empty cells below the last row with data are not counted in whole-column ranges.
